# SOC 2 prep

Date: 2026-05-09

MnemoPay is not ready for a Type II audit yet, but it can start collecting evidence now. This file is the operating checklist until a formal compliance tool is adopted.

## Scope

Initial scope:

- Hosted MnemoPay console/API.
- Hosted brain memory service.
- Payment rail orchestration.
- API key and webhook management.
- Production infrastructure on Fly/Vercel/Neon/Supabase/Stripe/OpenRouter.

Out of scope for first pass:

- Customer on-prem deployments.
- Mobile SDK offline storage.
- Third-party customer applications that only consume the SDK.

## First controls to implement

- Admin MFA required for hosting, database, Stripe, domain registrar, GitHub.
- No production secrets in repo or shared memory.
- API key create/revoke events logged.
- Namespace delete/export events logged.
- Dependency audit reviewed weekly.
- Deploys tied to git commit and status check.
- Incident log exists even when empty.
- Customer data deletion path documented.

## Open risks

- Hosted brain memories may contain sensitive customer or player text. Need deletion/export before selling to teams.
- Payment orchestration touches regulated adjacent workflows. Keep language precise: MnemoPay is infrastructure, not a bank.
- Agent Credit Score must remain agent/business reputation language, not consumer credit language.
- Public claims must match shipped controls. No SOC 2 claim until audit is complete.
